# Должники

Программа для управляющей организации (Windows и macOS): **по отчёту о задолженности, который присылает ЕИРЦ (ЕРЦ), находит
самых крупных должников-физических лиц и готовит документы для взыскания** — досудебные претензии, письма в ЕИРЦ и заявления
мировому судье о выдаче судебного приказа. Документы создаются в Word (`.docx`), их можно сразу править и печатать.

## Для чего нужна программа
ЕИРЦ ежемесячно присылает Excel-отчёт «Долг поквартирно»: построчно адрес, квартира, ФИО, сумма долга, дата последней оплаты.
В нём смешаны жители, организации, нежилые помещения и итоговые строки, а документы по каждому должнику приходилось бы собирать
вручную. Программа делает это за вас:

1. **Отбирает нужных.** Оставляет только физических лиц с долгом в жилых помещениях, сортирует и берёт первых N (по умолчанию 20 самых
   крупных должников; число и порядок сортировки настраиваются).
2. **Готовит документы** по образцам организации, подставляя реквизиты, адреса, суммы прописью и падежи ФИО:
   - **досудебная претензия** собственнику — со сроком оплаты и платёжным агентом (ЕИРЦ);
   - **письмо в ЕИРЦ** с просьбой предоставить сведения по начислению и оплате по списку адресов должников;
   - **заявление о выдаче судебного приказа** — на каждого собственника помещения (в нём указаны все сособственники, пени, периоды,
     госпошлина, приложения), с судебным участком мирового судьи и его судьёй.
3. **Хранит то, чего нет в отчёте:** реквизиты организаций, дома и даты начала управления, карточки помещений с паспортными
   данными собственников, список судебных участков.

## Как это работает, шаг за шагом
| Шаг | Что делать в программе |
|---|---|
| 1. Один раз настроить | Шестерёнка → **Организации…** (реквизиты, платёжный агент ЕИРЦ, подписант, дома с датами управления) и **Судебные участки** (загрузить список с sudrf.ru, при желании указать судей и адреса судов) |
| 2. Открыть отчёт ЕИРЦ | **Открыть Excel…** (`.xlsx`, `.xls`). Программа сама определяет организацию по заголовку и колонки ФИО / долг / адрес / квартира |
| 3. Отобрать должников | **Фильтровать** — остаются физлица с долгом; сортировка и число должников — в настройках. В таблице можно сортировать по заголовкам, листать страницы и **снять галочки** с тех, на кого документы не нужны |
| 4. Подготовить документы | Кнопка **Создать документы** (меню: претензии, письмо в ЕИРЦ, заявления о судебном приказе). Для заявлений заполняется карточка собственника (двойной клик по строке или правая кнопка → «Собственники помещения…»): ФИО, доли, паспорт, адреса, пени, периоды |
| 5. Проверить и отправить | Открыть `.docx` в Word, проверить пустые места (`____`), распечатать/подписать. Юридическую проверку текстов и размера госпошлины выполняет пользователь |
| 6. Передать коллеге | **Сохранить в Excel…** — отфильтрованный список; программа при открытии узнаёт его и работает с ним без исходного отчёта |

Чего в отчёте нет и что вводится вручную: паспортные данные и адреса регистрации собственников, доли в праве, пени и периоды долга,
номер лицевого счёта, платёжное поручение. Если поле не заполнено, в документе остаётся пустое место, а не выдуманное значение.

## Где хранятся данные и что уходит в интернет
Всё хранится локально в одной папке `~/.debtors/` в домашней папке пользователя (на Windows — `C:\Users\<имя>\.debtors`). Файлы, которые старые версии клали в домашнюю папку россыпью (`~/.debtors_*.json`), при первом запуске переносятся туда автоматически.


| Файл | Содержимое |
|---|---|
| `~/.debtors/settings.json` | настройки (колонки, число должников, сортировка, размер страницы…) |
| `~/.debtors/orgs.json` | организации, их дома, даты управления, участки домов |
| `~/.debtors/courts.json` | список судебных участков, ФИО судей и адреса судов (ваши правки) |
| `~/.debtors/owners.json` | **персональные данные собственников** (доступ только владельцу, права 600) |
| `~/.debtors/state.json` | состояние при закрытии (открытый файл, отметки) |

Файлы записываются **атомарно**: данные сначала идут во временный файл рядом, и только после записи на диск он переименовывается
поверх старого, поэтому сбой или выключение питания посреди записи не оставляют повреждённый файл. В каждом файле есть поле
`schema_version` (версия формата): файлы прежних версий без него читаются как есть и при следующем сохранении записываются в новом
формате; при смене формата программа переводит данные на новую версию сама. Если на диске файл более новой версии, чем знает
программа, перед записью его копия сохраняется рядом (`…vN.bak`). Организации, карточки и корзина теперь лежат под ключами
`organizations`, `cards`, `items`; более старые версии программы такие файлы не прочитают, поэтому при переходе обновляйте
программу у всех, кто обменивается файлами.

В интернет программа обращается **только** за публичным списком судебных участков на sudrf.ru (кнопка «Загрузить список участков»).
Отчёты, ФИО и персональные данные никуда не отправляются. Чтобы перенести данные на другой компьютер, скопируйте эту папку
(персональные данные передавайте защищённым способом).

## Как определяется физлицо
По порядку, первое сработавшее правило:
1. Строки без ФИО (итоги по домам и общий итог) пропускаются.
2. «ИП» в наименовании — по галочке «ИП считать физлицами» (по умолчанию нет).
3. Наименование содержит признак организации (ООО, АО, МУП, ТСЖ, «администрация», «магазин»… — список редактируется в
   «Признаки организаций…») или кавычки → организация.
4. ФИО должно выглядеть как «Фамилия Имя [Отчество]» кириллицей (допускаются инициалы, «оглы», «кызы»), без цифр.
5. Нежилые помещения пропускаются (галочка «Пропускать нежилые помещения»): номер квартиры не с цифры — «н/п…», «Магазин»,
   «подвал» и т. п.; квартира может быть записана и в адресе (`…-к.1`, `кв. 5`).

**Адрес из двух колонок.** Если в отчёте улица и номер дома лежат в разных колонках («Улица» = `10-й пер`, «Дом» = `114`),
программа находит обе (в настройках «Адрес дома (или улица)» и «Номер дома») и склеивает адрес: `10-й пер 114`. По нему работают
список домов организации, претензии, письмо и заявления. Организация может определяться по колонке «УК» или по домам.

Суммы понимаются в разных видах: `150000`, `1 234,56 руб.`, `1.234.567,89`. Нулевые и пустые суммы пропускаются.
Настройки запоминаются в `~/.debtors/settings.json`.

## Организации и претензии
- «Организации…» — список организаций: название, реквизиты для шапки, платёжный агент (ЕИРЦ), срок оплаты,
  текст претензии, **дома организации** (адреса как в отчёте). Хранится в `~/.debtors/orgs.json`.
- Настройки организации разбиты на вкладки: **Дома**, **Шапка** (реквизиты в верхней части претензии, письма и заявления), **Претензия**, **Письмо в ЕИРЦ**, **Судебный приказ**.
- Организация определяется по заголовку отчёта (слово из поля «автоопределение») или выбирается вручную.
  Если у организации заданы дома — в отбор попадают только строки этих домов; если пусто — все строки файла.
- «Сформировать претензии…» создаёт по одному docx на должника (все или только выделенные строки таблицы).

## Судебный приказ
- Двойной клик по строке результата (или правая кнопка → «Собственники помещения…») открывает карточку собственника: ФИО, дата и место рождения,
  паспорт, адреса, а также данные по делу (пени, периоды, лицевой счёт, платёжное поручение).
- Если ФИО в карточке заполнено — используется шаблон «собственник известен» (ФИО склоняется автоматически, можно поправить),
  если пусто — «собственник неизвестен» (с кадастровым номером и запросом данных у уполномоченных органов).
- «Заявления о судебном приказе» (пункт меню «Создать документы») создают по заявлению на каждый отмеченный адрес. Незаполненные поля остаются подчёркиваниями.
- Персональные данные хранятся только локально в `~/.debtors/owners.json` (доступ 600). В репозиторий и сборку не попадают.
- **Несколько собственников.** В карточке помещения можно добавить всех собственников («Добавить собственника»), у каждого свои
  ФИО, доля в праве, паспорт, даты, адреса. Заявление формируется на каждого собственника (файлы вида `05-1`, `05-2`),
  в каждом перечислены все собственники помещения и указано, что заявления на остальных подаются отдельно.
- **Суммы не делятся.** В каждое заявление идёт полный долг и пени по помещению. Доля в праве (если указана) только выводится
  в тексте заявления и в списке сособственников. Госпошлина в каждом заявлении своя. Старые карточки с одним собственником
  продолжают работать.

## Судебный участок в заявлении
- «Настройки → Судебные участки»: кнопка загружает публичный список участков мировых судей с sudrf.ru
  (название, код, адрес суда) для выбранных регионов (строка «Регионы» → «Выбрать…»: в списке название региона, поиск, можно отметить несколько; хранятся коды, например 61 — Ростовская область; выбор запоминается сразу). В списке регионы, для которых sudrf.ru отдаёт участки (80), и новые регионы: Крым (82), Севастополь (92), ДНР (80), ЛНР (81), Херсонская (84) и Запорожская (85) области. Самих участков новых регионов в публичном списке sudrf.ru нет, поэтому после загрузки программа сообщает, для каких регионов участков не нашлось; по Красноярскому краю и Санкт-Петербургу данных тоже нет, их в списке нет. Хранится в `~/.debtors/courts.json`.
- Участок берётся из списка домов организации (см. ниже); в карточке собственника он (как и «В управлении с») только отображается; если не указан, там есть кнопка перехода
  к списку домов организации. Для адресов без назначенного участка при формировании заявлений выбирается общий участок. Шапка суда и просительная часть формируются по образцу («Мировому судье в … районе / на судебном участке № N / адрес»).
- Участок выбирается в выпадающем списке с поиском по вхождению: набираете часть названия, номер или фамилию судьи
  («таганрог 10», «огск 5», «парахина»). Кнопка «Судья и адрес суда…» запоминает ФИО мирового судьи (строка «Судья: …»
  в шапке заявления) и исправленный адрес суда; правки не пропадают при обновлении списка.
- **Участок дома.** В «Настройки → Организации → Дома» у каждого дома есть колонка «Судебный участок»: выберите участок и
  нажмите «Назначить выбранным домам» (можно сразу нескольким). Такой участок подставляется в заявления автоматически;
  если у дома участка нет, при формировании заявлений появится общий выбор (только для таких адресов).
- «Настройки → Судебные участки → Судьи и адреса участков…»: таблица всех загруженных участков с поиском. Можно задать
  ФИО судьи и адрес суда (адрес — сразу нескольким выделенным участкам, например всем участкам Таганрога) и сбросить правки
  к данным sudrf.ru. Правки хранятся отдельно и сохраняются при обновлении списка.
- Определять участок по адресу программа не умеет: выбор делает пользователь. Если список не загружен или участок не выбран,
  в заявлении остаётся пустое место, которое заполняют в Word.

## Интерфейс на macOS и Windows
Элементы управления следуют правилам платформы:
- **macOS:** окно настроек в стиле системных настроек (переключатели-«таблетки», выпадающие списки со стрелками, скруглённые блоки); меню приложения с «О программе», «Настройки…» (⌘,) и «Завершить» (⌘Q), меню «Файл» и «Правка»; кнопка «Отмена» слева от главной, главная — крайняя справа; ⌘W закрывает окно; сочетания с ⌘.
- **Windows:** стандартные флажки и выпадающие списки (`Combobox`), блоки с почти прямыми углами; строка меню «Файл» (Открыть, Последние файлы, Настройки… `Ctrl+,`, Выход), «Правка», «Справка» → «О программе»; главная кнопка диалога слева, «Отмена» — крайняя справа; сочетания с `Ctrl`; чёткий текст на HiDPI-мониторах.
- Везде: Tab/Shift+Tab переходят по элементам (у переключателей и списков macOS есть рамка фокуса, пробел переключает/открывает), Esc закрывает диалог, Enter в диалоге с выделенной кнопкой нажимает её.
- Версия показана в «О программе» (подставляется из тега релиза при сборке в CI). Внешний вид на Windows проверялся только кодом (режим Windows в тестах), без реальной Windows.

## Даты и календарь
Везде, где вводится дата, **клик по полю** (или клавиши ↓ / F4) показывает **стандартный календарь операционной системы**, если он ещё
не показан: на macOS — системный `NSDatePicker` (календарь такого же вида, как в «Системных настройках») во всплывающей панели под
полем, на Windows — стандартный календарь Windows (MonthCalendar). **Фокус остаётся в поле**, поэтому дату можно набирать с клавиатуры
(«1.6.15», «2015-06-01» → «01.06.2015»), а календарь переходит на набранную дату. Календарь закрывается выбором дня, кликом вне поля,
Esc, Enter или уходом фокуса; в нём есть «Очистить». Tk не умеет встраивать системные элементы выбора даты, поэтому панель показывает
вспомогательный процесс (`osascript` / `PowerShell`). Если системного календаря нет (Linux) или он не открылся, используется календарь
самой программы. Переключатель **Настройки → Внешний вид → «Системный календарь»** (включён по умолчанию) отключает системный календарь.
Произвольный текст в поле остаётся как есть. Календарь есть в списке домов (дата прихода и дата ухода), в карточке собственника
(дата рождения, периоды долга и пеней) и в настройках организации (дата доверенности, подставляется с «г.»).

**Дома: приход и уход.** У каждого дома в списке (Настройки → Организации → Дома) есть «В управлении с» (дата прихода) и «Ушёл (по)»
(дата ухода); если дом ушёл, а дата неизвестна, отмечается «Ушёл, дата неизвестна». Для отбора «Только дома в управлении» дом считается
в управлении, если дата прихода есть и не в будущем, а дата ухода не наступила и нет признака «ушёл» без даты. Прежние записи («01.06.2015г ушел»,
«01.12.2019г-01.11.2020гг») при первом чтении разбираются на отдельные поля автоматически (схема файла организаций 2).
Не охвачены календарём поля, где дата — часть текста: «Платёжное поручение (№ и дата)», «Уведомление о лицензии (№ и дата)», «Счёт-извещение за (месяц)».

## Фильтрация при открытии
Переключатель **Настройки → Отбор → «Фильтровать при открытии файла»** (по умолчанию включён): сразу после открытия исходного отчёта
программа применяет фильтр, без нажатия «Фильтровать». Выключите его, если хотите сначала посмотреть весь файл. Если колонки ещё не
выбраны, файл просто загружается. Настройка запоминается. При запуске с восстановлением состояния фильтр строится по сохранённому состоянию.

## Только дома в управлении
Переключатель **Настройки → Отбор → «Только дома в управлении»** оставляет в отборе лишь дома, которые сейчас в управлении
организации, по полю «В управлении с» в списке домов (Настройки → Организации → Дома):
- дата не указана — дом **не в управлении** и в отбор не попадает;
- одна дата («01.06.2015г») — дом в управлении с этого дня (дата в будущем — ещё нет);
- период («01.12.2019г-01.11.2020гг») — дом в управлении, пока сегодня внутри периода;
- слова «ушел», «выбыл», «расторг…» в поле — дом уже не в управлении;
- непустой текст без распознанной даты считается заполненным (дом в управлении).

Если у организации вообще нет списка домов, отбор берёт все строки файла и переключатель ни на что не влияет. Число отброшенных
строк показано в нижней строке («не в управлении: N»).

## Госпошлина в заявлении
Размер госпошлины в заявлении о судебном приказе считается по ст. 333.19 НК РФ: по таблице ставок для иска имущественного
характера (редакция ФЗ от 08.08.2024 № 259-ФЗ) берётся пошлина по цене требования, и для судебного приказа — **50 %** от неё.
Цена требования — долг по помещению плюс пени из карточки (если указаны). Порядок выбора значения:
1. пошлина, указанная вручную в карточке собственника;
2. расчёт по НК РФ (переключатель **Настройки → Госпошлина → «Рассчитывать по НК РФ»**, включён по умолчанию);
3. если пошлины нет ни в карточке, ни расчёта (расчёт выключен или нет суммы), в заявлении остаётся пустое место для заполнения в Word.

**Настройки → Госпошлина → «Таблица ставок…»**: таблицу ставок и процент для судебного приказа можно править (закон меняется),
вернуть к НК РФ и проверить расчёт на любой сумме. В итоге создания заявлений показано, в скольких из них пошлина рассчитана.
Актуальность ставок проверяет пользователь.

## Сортировка
- **Настройки → Отбор → «Сортировать по»**: «Сумма долга» (по умолчанию, по убыванию — от большего к меньшему) или любая колонка файла
  (адрес, квартира, дата последней оплаты и т. д.), по убыванию или возрастанию. Даты, числа и текст распознаются автоматически
  («2» идёт перед «10»), пустые значения всегда в конце. Сортировка применяется до отбора: в список попадают первые N должников в этом порядке.
- **Текущая сортировка показывается в самой таблице**: у колонки, по которой отсортирован список, в заголовке стоит стрелка (▲ по возрастанию, ▼ по убыванию) — и для обычного, и для отфильтрованного файла. В строке состояния сортировка не дублируется.
- **Клик по заголовку колонки в таблице** сортирует уже отобранный список (первый клик — по возрастанию ▲, второй — по убыванию ▼).
  Отметки и документы привязаны к людям, а не к позиции в таблице, поэтому перестановка их не путает.

## Исходный и отфильтрованный файлы
- «Сохранить в Excel…» сохраняет отфильтрованный список и добавляет скрытый служебный лист `_debtors_meta` (колонки, организация,
  исходный файл). Файлы более ранних версий без него тоже распознаются — по структуре (лист «Топ-N…» + «Статистика»).
- При открытии программа сама определяет тип файла и показывает его справа от имени файла: **«исходный файл»** или **«отфильтрованный список»**.
  Исходный файл фильтруется как обычно. Отфильтрованный открывается сразу как готовый список: работают сортировка, страницы, отметки,
  претензии, письмо, заявления и повторное сохранение; кнопка фильтра показывает «Уже отфильтрован». Чтобы отфильтровать заново,
  откройте исходный файл.
- Отметки (снятые галочки) в Excel не сохраняются; между запусками их помнит функция «Запоминать состояние».

## Фильтр и страницы
- Кнопка **«Фильтровать»** отбирает должников по настройкам и превращается в **«Сбросить фильтр»**: сброс снова показывает весь загруженный
  файл (постранично), документы недоступны. Чтобы применить изменённые настройки, сбросьте фильтр и отфильтруйте заново.
- **Пагинация**: над таблицей справа — «⏮ ◀ Стр. N из M ▶ ⏭», диапазон строк и выбор размера страницы (20/50/100/200/500, запоминается).
  Сортировка по клику и отметки «✓» действуют на весь список, а не на одну страницу; «Выделить / снять всех» — все страницы сразу,
  а документы формируются для всех отмеченных строк, где бы они ни находились.

## Удобство работы
- Окно «Настройки» оформлено как системные настройки macOS: блоки-карточки в два столбца («Колонки файла», «Отбор», «Внешний вид», «Данные», «Организации», «Судебные участки»), переключатели и выпадающие списки со стрелками.
- Горячие клавиши: `⌘O` / `Ctrl+O` — открыть файл, `⌘,` / `Ctrl+,` — настройки, `F5` или `⌘Enter` / `Ctrl+Enter` — применить или сбросить фильтр, `⌘A` — выделить все строки таблицы, `⌘C` — копировать выделенные строки.
- Правая кнопка мыши по строке: карточка собственника, отметка, копирование.
- Тема оформления (как в системе / светлая / тёмная) выбирается в настройках, раздел «Внешний вид». Строки таблицы чередуются по цвету, как в Finder. На macOS тему даёт сама система; на Windows тёмная тема — собственная палитра (не проверялась на реальной Windows).
- Ширину колонок можно менять мышью — она запоминается (правая кнопка по заголовку → «Автоширина колонок» возвращает подбор по окну). Если текст в ячейке не помещается, при наведении показывается полный текст.
- Правая кнопка по заголовку колонки позволяет скрыть ненужные колонки и вернуть их («Показать все колонки»).
- Поле «Поиск» над таблицей (⌘F / Ctrl+F) оставляет строки с введённым текстом по всем колонкам; «Выделить / снять всех» действует на найденные строки.
- Суммы и числа с копейками показываются в одном формате (`1 234,50`) и выравниваются по правому краю.
- Колонка «Участок» с ✓ показывает, что для помещения известен судебный участок (закреплён за домом в списке домов организации); без ✓ при создании заявлений придётся выбрать участок вручную.
- Документы создаются одной кнопкой «Создать документы» (меню: претензии, письмо в ЕИРЦ, заявления о судебном приказе; в
  пунктах и на кнопке видно, сколько документов получится). Перед созданием показывается окно: что будет создано, чего не
  хватает (для заявлений — у каких адресов нет персональных данных или участка, со списком) и папка сохранения. Папка
  запоминается (по умолчанию `~/Documents/Должники`), изменить её можно кнопкой «Изменить…». Если документов три и больше,
  показывается индикатор выполнения с кнопкой «Прервать». В конце предлагается открыть папку.
- На пустом экране показана подсказка «Что делать дальше»; при самом первом запуске открывается приветствие.
- Последние файлы: кнопка ▾ рядом с «Открыть Excel…». Excel-файл можно бросить на значок программы (macOS) или открыть через
  «Открыть в…»; на Windows файл можно перетащить на .exe или передать как аргумент. Перетаскивание в окно программы
  недоступно: библиотека для него не работает с Tk 9.
- Размер и положение окна запоминаются. В настройках («Внешний вид») выбирается размер шрифта таблицы.
- Удалённая карточка собственника попадает в корзину на 30 дней; в карточке помещения есть кнопка «Восстановить
  удалённую карточку».
- «Настройки → Данные»: экспорт и импорт настроек, организаций, участков и карточек одним zip-файлом (для переноса на
  другой компьютер; в файле персональные данные). Перед импортом копия текущих данных сохраняется в `~/.debtors/backups`.
- Под таблицей показана сумма долга отмеченных адресов.
- В колонке «Данные» стоит ✓, если для помещения уже заполнены персональные данные собственника.

## Запоминание состояния
Настройка «Запоминать состояние при запуске» (шестерёнка → «Отбор», включена по умолчанию) возвращает при запуске то, что было при закрытии:
открытый файл и лист, выбранную организацию, отфильтрованный список (он строится заново по текущим настройкам) и снятые галочки.
Состояние хранится в `~/.debtors/state.json`; при выключенной настройке файл удаляется. Если файл прошлого сеанса перемещён, программа
сообщит об этом и запустится чистой.

## Запуск из исходников
Нужен Python 3.10+ с Tk (установщик с python.org включает его).
```
pip install -r requirements.txt
python app.py
```

## Сборка программы
- macOS: `./build.sh` → `dist/Должники.app`
- Windows: `build.bat` → `dist\Должники.exe`

Собирать нужно на той ОС, для которой программа. Либо загрузите проект на GitHub —
`.github/workflows/build.yml` соберёт обе версии автоматически (вкладка Actions → Artifacts).

`make_sample.py` создаёт тестовый `sample.xlsx`.
