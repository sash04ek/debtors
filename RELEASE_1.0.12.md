## Что исправлено
- Исправлено падение при запуске на Windows.
- Причина была в привязке события жестов трекпада `<TouchpadScroll>`. Оно существует только в Tk 8.7/9, а сборка для Windows использует Tk 8.6.
- Привязка обёрнута в `try/except TclError`, поэтому на Tk 8.6 событие просто игнорируется, а работа колеса мыши остаётся корректной.

## Проверка в CI
- В workflow сборки добавлен шаг «Проверка запуска».
- Smoke-тест запускает приложение и строит основные окна и диалоги: главное окно, настройки, организации, карточку собственника, таблицу, темы и календарь.
- Проверка выполняется на реальных Windows и macOS раннерах с Tk 8.6.
- Это позволяет выявлять такие ошибки до релиза и снижает риск падения у пользователей.

## Важно
- Это первая реальная проверка запуска на Windows: после исправления окно и диалоги строятся без ошибок.
- Визуально интерфейс на Windows пока не проверялся полностью; системный календарь Windows в smoke-тесте не запускается.
- Баг затрагивал все версии с поддержкой жестов трекпада; выпуск релиза актуален.

## Итог
Исправление внесено, проверка запуска добавлена в CI, релиз готов к публикации.
